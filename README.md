# Airwaves releases

Signed, notarised builds of **Airwaves**, the macOS menu bar radio for the RTL-SDR Blog V4, and the Sparkle appcast that installed copies read to update themselves.

- **Download the latest version:** the newest release on the right, or [airwaves.icu/download](https://airwaves.icu/download).
- **Already running Airwaves?** It checks for updates about once a day. Use **••• › Check for Updates…** to look now.
- Each release carries the DMG, its SHA-256 and `appcast.xml`. The appcast the app reads is served from `https://airwaves.icu/appcast.xml`.

Airwaves is open source under the MIT Licence. Issues and source: [github.com/gonzoinceng-ctrl/airwaves](https://github.com/gonzoinceng-ctrl/airwaves).
